# 任务卡模板

> 复制到 kanban 卡片 note，或 `tasks/<id>.md`。卡片只写“这次要交付什么”，不复制整份 PRD。

```markdown
## 目标
一句话，可验收。

## 背景 / 输入
- spec: docs/specs/<module>/spec.md
- 相关代码/调用链（文件:行）
- 相关 ADR / 旧实现

## 允许改
- 文件/目录白名单：

## 不要改
- 旧口径代码、无关页面、`.env`、`pb_data/`、其他模块契约

## 实现要点
- 数据：
- API：
- 页面/交互：
- 权限/审计：

## 验收
- AC 编号：
- 命令：
  - `pnpm typecheck`
  - 定向 `pnpm vitest run test/<file>.test.ts`
  - 新库烟测（如涉及 schema）
- 人工观察（如页面类）：

## 交付
- 分支 / worktree：
- 变更文件：
- 证据：命令 + 退出码 + 关键输出 / 截图路径

## 未做 / 风险
-
```

## 卡状态

| 列 | 含义 |
| --- | --- |
| Backlog | 还没排期 |
| Ready | 规格/依赖已就绪，可认领 |
| In Progress | 有 owner，正在写 |
| Review | 等 verifier / 人工验收 |
| Done | 有证据并通过 |

## 写卡规则

- 一张卡一个可独立验收的交付；不要把 3 个页面塞进一张卡。
- 允许改的路径必须和并行任务不重叠；重叠就拆卡或串行。
- 没有“验收命令”的卡不进 Ready。
- 卡里不写真实密钥、客户身份证、手机号原文。
