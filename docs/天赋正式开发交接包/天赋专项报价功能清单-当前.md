## 2026-11-04 调整口径

- 范围：后台管理与 C 端小程序两端，合计 48,000 元（后台 36,000 + C 端 12,000）。
- 删除：机构、代理商、服务商、培养计划、内容库、会员授权与 AI 辅助相关功能行，机构业务端整张明细表不再保留。
- 新增：天赋方向（要素 + 要求分级 + 权重，单方向权重合计 100，家长最多同时选择 3 个）。
- 匹配度：报告整份发布时生成快照，按加权达成度计算，80 及以上为高度匹配、60 至 79 为较为匹配、60 以下为关联较弱。
- 报告：仅后台审核、整份发布与整份撤回；撤回后 C 端报告、要素解读与方向候选同步不可见。
