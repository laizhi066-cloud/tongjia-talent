## 1. 背景与目标

### 1.1 业务背景

同佳天赋面向「基因检测 → 天赋解读 → 培养方向」业务：外部基因检测机构出具《个性化能力培育开发基因服务报告》（A~F 六册），外部培育建议系统按「姓名 + 具体年龄」输出配套培育建议；家长在小程序中阅读报告与建议，依据报告命中结果选择培养方向与目标档位，后续由线下团队联系与排师。平台本身**只做同步、配置、发布与展示**，不生产报告与建议正文。

### 1.2 产品目标

1. 后台可完成会员建档、报告同步与发布、建议版本管理、天赋规则与培养方向配置；
2. 家长端可在不接触后台术语的前提下读懂报告、建议，并完成方向与档位选择；
3. 报告发布后内容冻结，后台后续调整配置不影响历史报告；
4. 全链路留痕：发布、撤回、恢复、补发、方向选择、建议版本同步均可在后台回溯。

### 1.3 成功指标（建议，正式版需埋点）

| 指标 | 定义 |
| --- | --- |
| 报告触达率 | 已发布报告 / 已出结果报告 |
| 报告打开率 | 家长进入报告页的已发布报告占比 |
| 方向选择率 | 已完成方向选择的报告 / 可读报告 |
| 建议阅读率 | 打开过建议书的家长 / 有建议的家长 |
| 发布时效 | 报告生成到发布的中位时长 |

| 角色 | 端 | 职责 | 可见范围 |
| --- | --- | --- | --- |

## 3. 范围

### 3.1 本期范围

**后台管理（6 个一级分组 / 11 个二级菜单）**

```
工作台     ─ 工作台与待办
会员管理   ─ 会员管理
培养方向   ─ 培养方向管理
天赋规则   ─ 潜质要素 / 分级与固定注解
报告管理   ─ 基因报告 / 培育建议
系统管理   ─ 用户列表 / 菜单管理 / 角色管理 / 操作日志
```

**C 端小程序（4 个主栏目 + 二级页）**

```
首页 / 报告 / 培养方向 / 我的
```

## 4. 业务规则（BR）

| 编号 | 规则 |
| --- | --- |
| BR-01 | 单实例、单数据库；不做多租户、不做站点切换。 |
| BR-02 | **基因报告一人一份**：一个测评对象（本人或子女）只有一份报告，重复查询只刷新状态，不重复建档。 |
| BR-03 | **发布即冻结**：报告发布时冻结要素结果、固定注解、六册开放范围、方向命中与档位；后续配置调整不回写历史报告。重新发布/补发/恢复才产生新版本。 |
| BR-04 | **固定六册**：A~F 对应生长发育、智商、情商、领导商、艺术商、体育运动商；发布时逐册勾选开放范围。 |
| BR-05 | **增量分册**：外部可能先出 2 册、后补 3 册。新增 = 外部已出篇目 − 已发布分册；后台标「新增分册」并可一键补发，补发只追加新增册，原分册内容不动。 |
| BR-06 | **建议与报告同发**：报告发布/恢复时，该对象当前周期的建议一并置为已发布；报告不可读时建议不可见。 |
| BR-07 | **建议按周期更新**：默认 4 个月一版；新版本生效后旧版归档只读，C 端只展示当前生效版本；报告本身不随版本变化。 |
| BR-08 | **方向命中**：要素实际分级级序 ≥ 要求分级级序记 1 条命中；按命中条数降序，同数依次比较命中率、配置条数、方向编码；家长端推荐最多 5 个，已选上限 3 个。 |
| BR-09 | **没有匹配也可选**：报告可读但 0 命中时列出全部已配置方向并标「暂无匹配」；发布快照里没有任何方向时推荐页为空，家长可从后台方向中自选或自己填写（≤10 字）。 |
| BR-10 | **撤回口径**：报告撤回后 C 端显示「报告内容更新中」，分册、下载、建议均不可见；恢复发布后恢复。后台列表仍保留「已撤回」。 |
| BR-11 | **敏感信息**：手机号、身份证默认脱敏；家长身份证选填；子女身份证必填且校验 18 位与出生日期一致；全号查看需授权并留痕。 |
| BR-12 | **编码不对家长展示**：要素编码（如 A-01）、分册字母等内部编码不出现在小程序；后台保留编码用于定位与检索。 |
| BR-13 | **列表规范**：一个表头只对应一个字段；筛选各项独立生效、同时填写取交集；分页每页 20 条。 |
| BR-14 | 原型特有：数据存浏览器本地、支持「重置数据 / 恢复演示数据」；**正式版必须移除**，改为真实持久化。 |

## 5. 信息架构

### 5.1 后台

- 侧栏为可折叠两级树，一级分组带图标与二级数量，当前项自动展开并高亮；顶部「全部展开 / 全部折叠」。
- 页面形态：工作台为卡片看板；其余 10 页为「检索条 + 单张表格 + 分页」；复杂内容用弹层 + 页签。
- 弹层尺寸：普通 / wide（发布、建议书、版本）/ ultra（会员详情、历史版本）。

### 5.2 C 端

```
登录（协议勾选 + 微信一键登录）
首页：对象卡 → 待核对提示（如有）→ 四宫格入口 → 页脚说明
报告：对象条 + 页签「基因报告 / 培育建议」
  ├ 基因报告：状态卡 或 分册目录（6 行，未检测/未开放置灰）
  │   └ 分册页：数据熵筛选 → 章节 → 要素行
  │       └ 要素解读：数据熵、天赋解读、相关方向、上一项/下一项
  └ 培育建议：按分册 → 建议书（四段家长文案）
培养方向：页签「推荐方向 / 已选方向」
  ├ 推荐：方向卡（命中数）→ 方向详情 → 目标档位 → 确认选择
  ├ 已选：取消选择 / 更换档位
  └ 选择方向（自己填写）：方向下拉（拼音排序）+ 培养目标
我的：家长资料 → 编辑资料 / 孩子管理 / 更多设置 → 退出登录；更多设置内含用户协议、隐私政策、关于与版本、联系客服与注销账号
```

## 6. 后台功能需求

### 6.1 工作台（FR-ADM-01）

**目标**：一屏看清规模与待处理量，并能直达列表。

**指标卡（4 张）**

| 卡片 | 口径 | 点击 |
| --- | --- | --- |
| 注册家长 | 家长账号数；脚注「绑定 N 名子女」 | 会员管理 |
| 已出结果 | 查询状态「已查到」的子女数；脚注「待出结果 N 人」 | 会员管理 |
| 已发布报告 | 状态「已发布」的报告数；脚注「待发布 N 份 · 已撤回 N 份」 | 基因报告 |
| 待处理事项 | 待发布 + 查询未完成 + 已发布未选方向 + 已撤回待确认 + 自定义方向待归并 | 纯汇总卡，不可点（**待定项，见 13.3**） |

**最近操作**：展示最近 6 条操作日志（时间、操作人、动作、内容），「查看全部」进入操作日志。

**验收**

- AC-ADM-01-1 四张卡数值与对应列表条数一致；
- AC-ADM-01-2 前三张卡可点且落到对应列表；
- AC-ADM-01-3 最近操作按时间倒序，最多 6 条。

### 6.2 会员管理（FR-ADM-02）

**列表（8 列）**：会员编号、家长（可点开详情）、手机号、家长身份证、名下子女（只显示人数）、关联报告（份数）、账号状态、操作。

**检索**：家长姓名、手机号、子女姓名、账号状态下拉（选项带数量）。四项取交集；「重置」清空全部。

**行内操作**：详情（主）、编辑、停用/启用。

**详情弹层（ultra）**

- 顶部信息条：会员编号、家长姓名、手机号、家长身份证；
- 页签：名下子女 / 关联报告 / 账号资料。

| 页签 | 内容 | 操作 |
| --- | --- | --- |
| 名下子女 | 子女、与家长关系、身份证号、查询状态（含原因）、关联报告 | 编辑（就地展开面板）、重新查询（未查到/查询中）、恢复演示数据（原型）、解绑（二次确认） |
| 关联报告 | 报告编号、子女、状态、已选培养方向、目标档位、开放分册 | 查看报告 |
| 账号资料 | 会员编号、姓名、手机号、身份证、状态、来源、注册时间、子女数、报告数 | — |

**子女编辑面板字段**：姓名（必填）、性别、亲属关系（父亲/母亲/祖父/祖母/外祖父/外祖母/其他监护人）、出生日期（必填）、身份证号（新增必填，编辑留空表示不改）。校验：18 位、与出生日期一致；保存后发起主动查询。

**新建会员**：同一表单录入家长资料 + 多名子女，保存后逐个发起查询。家长身份证选填。

**业务规则**：一个家长一行；子女为独立档案（`parentId` 关联），不嵌在会员记录内；解绑后家长端不可见，历史报告保留在后台。

**验收**

- AC-ADM-02-1 列表 8 列一列一字段，无副行堆叠；
- AC-ADM-02-2 四项筛选可叠加，重置后恢复全量；
- AC-ADM-02-3 编辑子女保存后查询状态变「查询中」，回执到达后就地刷新；
- AC-ADM-02-4 编辑态不回显脱敏证件号，留空不修改；
- AC-ADM-02-5 解绑需二次确认，确认后家长端不可见。

### 6.3 培养方向管理（FR-ADM-03）

**列表（7 列）**：编码、培养方向（名称 + 一句描述）、关联要素与要求分级（前 3 项 + 「等 N 项」）、启用档位、默认档位、状态、操作。

**检索**：方向名称、方向编码。

**操作**：新增方向、配置、停用/启用、删除。删除前校验是否已被报告选择引用，被引用只允许停用。

**配置弹层**

- 要素来源：天赋规则 → 潜质要素文库（6 分册 / 158 项），支持分册筛选、多选、逐项设置「要求分级」；
- 不设权重、不校验合计 100；
- 目标档位：勾选适用档位子集 + 指定默认档位（档位为系统预置 4 档）；
- 保存校验：至少 1 项要素、要求分级合法、至少 1 个目标档位；
- 保存后生成方向新版本，历史报告不受影响。

**档位维护**：4 个预置档位（启蒙/养成/精进/冲刺，对应普通/资深/卓越/大师级老师）可编辑文案、停用、设全局默认；不提供新增档位。

**自定义方向归并**：家长自填方向进入「待归并」，可归并到正式方向（写别名）或转为正式方向（生成停用方向待配置）。**原型当前无页面入口，正式版需补入口（见 13.4）**。

**验收**

- AC-ADM-03-1 表头 7 列，行内 7 个单元格对齐；
- AC-ADM-03-2 配置弹层只列 158 项文库要素，分册筛选与数量正确；
- AC-ADM-03-3 保存缺要素/缺档位时阻断并提示；
- AC-ADM-03-4 已被报告引用的方向不可删除。

### 6.4 潜质要素（FR-ADM-04）

**定位**：外部系统按「性别 + 具体年龄」同步的只读文库，后台只同步与查看，不新增/编辑/停用。

**列表（7 列）**：要素编号、潜质要素、所属分册、数据熵分级（12 槽位）、文案槽位、回填状态、操作（查看文案）。

**检索**：要素编号、潜质要素、分册下拉（全部分册 + 6 册带数量）。

**能力**：切换性别与年龄库、同步该库、导出、下载模板；文案弹层展示「一项要素 × 4 档数据熵 × 3 变体」共 12 条槽位，未回填显示「待补写」。

**验收**

- AC-ADM-04-1 共 158 项、6 分册，数量与文库一致；
- AC-ADM-04-2 检索与分册下拉可叠加；
- AC-ADM-04-3 页面无新增/编辑/停用入口。

### 6.5 分级与固定注解（FR-ADM-05）

**页签**：固定注解（158 × 4 = 632 条）/ 分级设置（4 档）。

**检索**：分级下拉（全部 + LV1 常态/LV2 优良/LV3 优秀/LV4 卓越，带数量；两个页签共用）、要素编码、潜质要素、注解内容。

**固定注解表（9 列）**：注解编号、要素编码、潜质要素、分级、注解正文、年龄条件、性别条件、状态、操作（编辑/停用/删除）。要素名称取潜质要素文库当前值，避免快照漂移。

**分级设置表（7 列）**：分级编码、分级名称、级序、得分范围、固定注解数、状态、操作（编辑/删除）。

**能力**：增删改查、数据导入（字段映射 + 校验预览 + 失败明细）、下载模板、导出。编码为唯一标识，编辑不可改；被方向引用的要素/分级只允许停用。

**验收**

- AC-ADM-05-1 固定注解 632 条、分级 4 条；
- AC-ADM-05-2 分级下拉筛选后条数与选项一致；
- AC-ADM-05-3 导入可预览通过/失败行，失败行不写入。

### 6.6 基因报告（FR-ADM-06）

**列表（10 列）**：报告编号、家长、子女、家长手机号（脱敏）、检验人身份证（脱敏）、基因篇数、分册（外部已出编码）、**新增分册**、状态、操作。

- 新增分册 = 外部已出 − 已发布；显示 `N 篇` + 编码（如 `3 篇 CDE`），无新增显示「—」；
- 状态仅三态：待发布 / 已发布 / 已撤回。

**检索**：报告编号、子女姓名、家长手机号、检验人身份证，四项输入 + 发布状态下拉（全部/待发布/已发布/已撤回，带数量）。

**行内操作**

| 操作 | 出现条件 | 说明 |
| --- | --- | --- |
| 详情 | 全部 | 打开报告详情（4 页签） |
| 基因报告 | 已同步基因报告 | 查看外部报告元数据与篇目 |
| 发布 | 待发布 | 弹层勾选开放分册 + 预览方向命中 → 确认发布，冻结快照 |
| 撤回 | 已发布 | 二次确认，C 端立即不可见 |
| 恢复发布 | 已撤回 | 沿用原快照恢复，C 端重新可见 |
| 补发 | 已发布且存在新增分册 | 弹层列出新增册，确认后只追加新增分册 |

**一键同步全部报告**：以子女身份证号为主键批量拉取；弹层预演「刷新同步 / 新建报告 / 外部暂无数据」三类人数与逐人明细，确认后写入，写同步日志与操作日志。

**发布弹层**：信息条（报告编号、要素数、方向数、档位数、当前版本）+ 六册勾选 + 方向命中结果预览 + 冻结规则说明。

**补发弹层**：外部已出（N 册，编码）、本次新增（N 册，编码）、补发规则（只追加新增册，原分册内容不变，写版本历史与日志）、新增册清单。

**报告详情（弹层，4 页签）**

| 页签 | 内容 |
| --- | --- |
| 已选培养方向和目标 | 培养方向、目标档位、建议师资、提交时间、类型（正式/自定义） |
| 匹配天赋 | 方向、发布时命中 vs 当前配置命中、配置是否已变更；可「按当前配置重新生成快照」 |
| 基因报告 | 六册开放状态、章节数、要素数；每册「详情」叠加层（要素编码、潜质要素、数据熵、章节、固定注解） |
| 培育建议 | 该对象当前生效版本的建议书覆盖册与状态，可逐份查看 |

**验收**

- AC-ADM-06-1 表头 10 列，新增分册列只在有新增时显示内容；
- AC-ADM-06-2 发布后状态变已发布、C 端可读，快照版本 +1；
- AC-ADM-06-3 撤回后 C 端显示「报告内容更新中」，恢复后恢复；
- AC-ADM-06-4 补发只追加新增册，原分册章节与要素不变；
- AC-ADM-06-5 报告详情 4 页签可切换，旧页签链接自动回落。

### 6.7 培育建议（FR-ADM-07）

**列表（15 列）**：建议编号、版本、本人、身份证、性别、出生日期、年龄、基因报告、基因篇数、分册、覆盖要素、数据熵、发布状态、同步时间（含撤回时间副行）、操作。表格支持横向滑动，操作列固定在右。

**检索**：建议编号、子女姓名、身份证、报告编号、年龄（精确周岁）。尾部「接收新一版建议」。

**能力**

- 接收新一版：选同步日期 → 生成新版本，旧版归档，C 端切到新版；
- 版本历史：按版本看份数与状态，只读回溯；「回到当前生效版」；
- 建议书：按分册展示四段家长文案（分级内容/分级举例/培育方向/培育建议）；
- 发布/撤回：仅当前生效版本可操作，历史版本只读；
- 导出。

**口径**：外部系统同步即默认已发布；后台逐份撤回后家长端立即不可见；正文只同步不改写。

**验收**

- AC-ADM-07-1 15 列对齐，操作列固定；
- AC-ADM-07-2 年龄按精确周岁匹配（输 7 只命中 7 岁）；
- AC-ADM-07-3 撤回后 C 端对应建议消失，发布后恢复；
- AC-ADM-07-4 切到历史版本出现「历史版本只读」提示，发布/撤回按钮隐藏。

## 7. C 端功能需求

### 7.1 登录（FR-APP-01）

品牌标识 + 产品名 + 一句话说明 + 协议勾选 +「微信一键登录」。未勾选协议不可登录。账号停用显示停用页。

### 7.2 首页（FR-APP-02）

- 对象卡：当前测评对象（本人/子女）、性别年龄、点击切换；
- 脚注：`可读册数` / `报告整理中` / `报告内容更新中` / `结果查询中` / `信息待核对` / `尚未查询`；
- 待核对提示：查询状态不是「已查到」的孩子数量，点击进孩子管理；
- 四宫格：报告与分册、培育建议、培养方向、孩子管理；
- 页脚说明（小字）。

### 7.3 报告页（FR-APP-03）

- 顶部对象条（唯一切换入口）；
- 页签：基因报告（可读册数）/ 培育建议（份数）；
- 报告不可读时只显示状态卡，不列分册、不提供下载；
- 可读时列全 **6 册**：可读册可点进详情；未检测标「未做报告」；检测未开放标「未开放」，均置灰不可点；
- 表头：全开显示「6 篇」，部分开放显示「共 6 册 · N 册可读」。

### 7.4 分册页（FR-APP-04）

- 分册头：册名、系列、第 N 分册；
- 数据熵筛选：全部 + 本册实际出现的数据熵分类（动态生成），筛选值按册记忆，再点已选项即取消；
- 章节分组 + 要素行（名称 + 数据熵标签，**不展示要素编码**）；
- 底部「下载本册 PDF」（仅开放册）。

### 7.5 要素解读（FR-APP-05）

数据熵、天赋解读话术、适用条件（如有）、相关培养方向（命中 N/M）、上一项/下一项（限本分册内循环）、返回来源页。

### 7.6 培育建议（FR-APP-06）

- 按分册展示，一册一份，各自编号；
- 列表显示份数、版本、生效周期（每 4 个月更新）；
- 详情四段：分级内容、分级举例、培育方向、培育建议；
- 数据熵筛选：详情顶部给「全部 + 本份实际出现的等级」，命中数显示「已选 / 总数」；筛选值按分册各自记忆（`adv:<分册>`），与报告分册页的筛选互不干扰，点已选项取消；
- 撤回的建议不展示；报告不可读时不展示建议。

### 7.7 培养方向（FR-APP-07）

- 页签：推荐方向（按命中条数降序，最多 5 个）/ 已选方向（N/3）；
- 0 命中：列出全部后台方向，标「暂无匹配」；
- 快照无方向：空态「暂无可推荐方向，可自己填写」；
- 方向详情：命中 N/M、要素对照（需 X · 现 Y / 已达成 / 差 N 级）、目标档位（含师资与频次）、确认/更新；
- 已选：取消选择、更换档位；
- 自己填写：方向下拉（按拼音首字母排序，末位「其他（自己填写）」≤10 字）+ 培养目标必选；
- 提交上限 3 个，超出提示先取消。

### 7.8 我的（FR-APP-08）

家长资料（头像、姓名、手机号、身份证）→ 编辑资料 / 孩子管理 / 更多设置 → 退出登录。低频内容收进「更多设置」：用户协议、隐私政策、关于与版本、联系客服、注销账号；「我的」页不再单列版本与协议入口。

- 编辑资料：姓名、手机号、性别、出生日期、身份证（选填）；
- 孩子管理：列表（姓名、性别年龄、查询状态、篇数）→ 编辑 / 新增；
- 孩子信息：姓名、性别、亲属关系、出生日期、身份证（编辑时留空不改）。

### 7.9 切换对象（FR-APP-09）

固定「本人」+ 名下子女；每项显示性别年龄与报告状态（`N 篇可读 / 报告整理中 / 报告更新中 / 报告未发布 / 报告待同步`）；切换后回来源页。同一时刻只呈现一个对象。

### 7.10 C 端状态文案

| 场景 | 文案 |
| --- | --- |
| 报告已发布 | `N 个分册可读` |

### 8.3 状态机

**报告**

```
待发布 ──发布──> 已发布 ──撤回──> 已撤回 ──恢复──> 已发布
                       └──补发新增分册──> 已发布（版本+1，分册增加）
```

**查询**：未查询 → 查询中 → 已查到 / 未查到（可重新查询回到查询中）。

**建议**：已发布 ⇄ 已撤回；版本维度：当前生效 → 已归档（新版本生效时）。

**方向选择**：未选择 → 已选（≤3）；可取消、可更换档位；自定义方向进入「待归并」。

## 10. 权限与安全

1. **数据权限**：家长只能访问本人与已绑定子女；子女解绑/账号停用后立即失效。
2. **敏感字段**：手机号、身份证默认脱敏（前 4 + 后 4）；全号查看需独立权限并写日志；数据库存加密值。
3. **审计**：发布、撤回、恢复、补发、建议版本、方向配置、子女解绑、账号停用等关键动作必须落操作日志。
4. **文件**：报告 PDF 不暴露对象存储直链，走服务端签名/代理，带时效与水印。
5. **接口**：后台接口按角色鉴权；C 端接口校验报告归属与状态，未发布/撤回/解绑一律拒绝。

### 13.1 必须补齐（原型未实现）
