## 2026-09-21：天赋闭环复审与流程图更新

本次复审将天赋专项按“平台管理端、机构业务端、第三方结果、C 端与服务机构”四条泳道重新梳理，使用 6 个阶段、91 个操作节点和 98 条连接，替换报价单“天赋专项流程图”页中的原图。图中每个节点都对应一个可执行动作、判断或异常回路，客户可沿箭头从会员登记追踪到报告查看和授权。

复审后的正常路径：

1. 平台建立机构资料，一期客户流程按机构类型单选为代理商或服务商；内部可以兼容后续资格扩展，但不在客户报价单、功能清单和流程图中展示机构同时具备两种资格。
2. 服务商维护培训机构，培训机构维护课程；培养计划关联一个或多个培训机构，再从已关联培训机构中选择课程。
3. 代理商登记本人或孩子，孩子必须绑定一位有效家长；登记可保存草稿、补充资料和提交，代理商业务端不提供付费确认。
4. 平台统一校验会员资料、家长关系、外部受检人标识和代理商引流归属；线下付费确认由平台后台处理。
5. 第三方基因检测系统返回约定结果，平台负责接收、去重、匹配会员、完整性检查和异常处理；样本采集、实验室检测和物流不属于本项目。
6. 平台分别生成检测报告和要素解读；要素解读调用分类、要素、分级、固定注解、年龄性别条件和培养内容，不能改写检测报告原文。
7. 服务商培养计划经平台审核后上架，系统按检测结果和培养意向最多推荐 3 个计划。
8. C 端只展示培养计划、检测报告、要素解读三个主入口；推荐候选最多 N 个（默认 3），客户单选一个计划及服务商，确认共享资料及已发布报告后建立幂等授权。
9. 服务商只读查看授权客户，代理商查看自己引流客户的已发布报告和 PDF；报告更新、撤回、授权取消和机构停用均同步控制可见范围。

异常闭环已覆盖：家长关系校验失败、导入错误、重复结果、结果匹配失败、结果缺失、规则或固定注解缺口、培养内容缺失、计划审核退回、无适配计划、客户未确认共享、授权取消、机构停用和报告撤回。异常均回到平台处理，修正后重新校验，不直接生成或展示未审核内容。

本次同步的原型口径：代理商页面移除“确认付费”操作，仅保留草稿、补资料和提交；机构类型表单一期仅展示代理商、服务商两种类型；完整流程页改用详细泳道流程图。

流程图文件：`docs/customer-review/天赋专项完整闭环流程图-详细.png`（详细操作版，6 个阶段、91 个节点、98 条连接）；客户阅读版：`docs/customer-review/天赋专项完整业务流程图-mermaid.png`，同样保留 91 个节点和 98 条连接，采用 Mermaid 风格深色节点、判断节点和异常回流。报价单“天赋专项流程图”页已嵌入 Mermaid 风格图片；原型同步图片仍保留详细操作版：`docs/customer-review/talent-prototype/assets/images/talent-full-closure-flow.png`。

本轮全局链路复核结论：机构建立 → 用户和角色分配 → 代理商登记会员或平台维护会员 → 家长/孩子关系和培养意向 → 第三方结果接收 → 结果匹配与报告详情 → 发布前付费提示 → 整份报告发布 → C 端选择培养计划和服务机构 → 平台授权 → 服务商会员管理只读查看 → 代理商按引流归属查看已发布内容。异常、撤回、授权取消、机构停用、角色停用均回到平台处理并同步收紧可见范围。

代理商会员页面的二级菜单和页面标题统一为“会员管理”；页面内保留“新增会员登记”按钮，新增动作进入同一套会员登记表单。此前的“会员登记”仅作为按钮动作语义保留，不再作为列表菜单名称。

## 2026-09-22：正式开发交接清单（当前生效）

本节是正式开发的启动依据。开发时以本节和前文当前生效口径为准，不需要重新检索旧会议纪要、旧报价单或旧原型说明。

### 一、必须落地的数据对象

- 机构：机构资料、机构类型（代理商/服务商）、资格状态、联系人和停用状态。
- 用户：登录账号、所属机构、账号状态、初始密码处理、最后登录时间。
- 角色：角色标识、适用机构类型、菜单/操作权限、数据范围、可选机构范围、启停状态。
- 会员：本人或孩子标识、姓名、手机号（家长登录使用）、外部受检人标识、来源渠道、代理商引流归属。
- 家长关系：家长、孩子、关系类型、有效状态、生效时间；一个孩子只能有一位有效家长，一个家长可关联多个孩子。
- 培养意向：标准方向、自定义方向、原始描述、主要意向、意向顺序、登记备注、草稿/已提交状态。
- 天赋规则：分类、要素、分级、结果范围、固定注解、年龄条件、性别条件、培养内容、匹配规则和启停状态。
- 培训机构与课程：服务商所属培训机构、培训机构下课程、启停状态；培养计划只能关联已启用的培训机构及其课程。
- 培养计划：平台或服务商来源、关联培训机构、关联课程、关联要素/分级/方向、适用条件、审核状态、上架状态。
- 检测结果：外部报告编号、外部受检人标识、分析时间、接收原文/结构化内容、接收状态、重复判断、匹配状态和异常原因。
- 天赋报告：检测报告快照、6 册内容、当前发布状态、已开放分册、PDF（第三方返回或补充上传）、当前版本和历史版本。
- 要素解读：基于检测结果固化的要素、分级、固定注解、年龄性别引导和培养内容命中快照，与检测报告分开存储和展示。
- 客户授权：会员、服务商、可查看内容范围、具体服务商用户（需要按本人数据隔离时）、共享确认时间、授权状态和取消时间。

### 二、必须落地的菜单和页面归属

- 平台管理端：工作台、系统设置（用户列表/角色列表/机构列表）、代理商管理、服务商管理、会员管理（含授权列表）、天赋规则（分类与要素/分级与固定注解/内容库与培养内容/匹配规则/培养计划/AI 辅助建议）、报告列表（报告列表/接收列表）、完整业务流程。
- 机构业务端：工作台、会员管理、报告列表（代理商按引流归属查看；服务商按平台授权查看）、课程管理、培养计划。代理商和服务商共用会员列表与会员详情代码，数据范围和可执行操作按角色区分；服务商页面不展示授权状态和授权管理按钮。
- C 端小程序：培养计划、检测报告、要素解读三个主入口；支持孩子切换、计划多选、服务机构多选、共享确认和授权结果查看。

### 三、必须落地的权限判定

每个查询和详情接口都要在服务端执行以下顺序，不能只依赖前端隐藏菜单：

1. 校验用户账号、所属机构和机构资格是否有效；
2. 校验角色是否启用，以及角色是否拥有当前菜单和操作权限；
3. 按角色数据范围计算可见机构/用户范围（全部、自定义、本机构、本机构及下属、仅本人）；
4. 叠加天赋业务关系：代理商仅能看自己引流客户，服务商仅能看平台授权客户；
5. 对报告、PDF、要素解读和培养计划详情再次执行同一数据范围校验；
6. 平台授权、报告撤回、规则审核和机构资格操作只允许平台角色执行；报告发布仅由平台执行，服务商按授权范围只读查看，代理商只能查询已发布报告；
7. 机构停用、资格停用、角色停用、授权取消或报告撤回后，相关数据立即不可见。

### 四、必须落地的关键业务接口/动作

- 会员登记、本人/孩子判断、家长关系绑定/更换/解绑、统一导入预览/校验/确认导入。
- 培养意向草稿保存、编辑、删除、提交；自定义意向 AI 归类/方向建议/草稿生成，人工确认后才进入正式规则或计划。
- 第三方结果接收、外部标识匹配、重复识别、完整性检查、失败重试、人工关联和接收状态查询。
- 检测报告生成、要素解读生成、规则命中快照生成；报告详情必须可查看原始结果、命中规则、分级、固定注解和培养内容。
- 报告列表发布动作中的线下付费提示；发布弹框选择本次开放分册，整份报告一起发布；撤回整份报告并同步隐藏已开放分册和 PDF；不做续费状态，不做单册独立撤回。
- PDF 补充/替换作为预留动作，不强制要求 PDF 才能发布结构化结果。
- 服务商服务商培养计划的新增/编辑/启停；计划审核通过后上架，审核退回可修改后重新提交。
- C 端推荐最多 3 个计划；客户可多选计划和服务机构，确认共享资料及已发布报告后创建授权。
- 平台授权列表新增、取消、重新授权；服务商会员管理只读展示被授权会员，服务商报告列表只读查看已授权且已发布报告；代理商报告列表按引流归属展示已发布内容且只能查询。

### 五、正式开发验收场景

- 新增孩子时没有有效家长不能保存；更换家长后旧关系失效；一个家长可以有多个孩子。
- 统一导入能预览、指出错误行、修正后重新上传并只确认有效数据；重复手机号和外部受检人标识被拦截。
- 角色没有菜单权限时不能进入页面；只有菜单权限但没有数据范围或业务授权时不能查看客户详情和报告。
- 同一服务商多个用户按角色数据范围和具体用户授权隔离数据；服务商端不显示授权管理状态。
- 第三方结果重复回传不会生成重复报告；匹配失败可人工关联并重新校验；结果缺失、格式异常和重试状态可查询。
- 报告详情能看到真实原始结果、规则命中明细和推荐计划；命中结果与会员详情中的要素解读使用同一份固化快照。
- 发布报告时先提示线下付费，必须至少选择一册；平台或已授权服务商完成发布后，C 端、代理商和已授权服务商按权限看到相同的已发布范围；代理商不提供发布按钮。
- 撤回报告后 C 端、代理商、服务商和 PDF 同步不可见；后台仍可查看历史版本，历史版本不能回滚。
- 服务商计划未绑定有效培训机构/课程不能提交；审核退回可修改后重新提交；停用机构或课程后计划不能上架。
- AI 对未配置的“笛子”等方向只生成待确认建议和草稿，人工确认并补齐规则、分级、注解、内容、机构和课程后才能启用。
- C 端只出现培养计划、检测报告、要素解读三个入口；报告与要素解读分开展示，培养计划不改写检测报告。
- 机构停用、角色停用、服务商资格停用和授权取消后，相关用户或数据立即按权限失效。

说明：分册是第三方固定返回的报告内容和本次发布时的开放选择；正式页面和接口只提供“整份报告发布/整份报告撤回”，不提供单册独立发布、单册独立撤回或续费状态。原型为兼容历史演示数据而保留的分册字段/测试动作，不作为正式开发范围。
