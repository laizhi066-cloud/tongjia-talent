## 2026-11-04 报价范围调整

当前报价为**后台管理 + C 端小程序**两端，合计 48,000 元（40 人天 × 1,200 元，后台 293 个功能点、C 端 159 个功能点）。机构、代理商、服务商、培养计划、内容库、AI 辅助与跟进流程均不纳入本次报价。

- 要素解读保留「结果值 → 分级 → 固定注解」链路与命中快照，固定注解可带年龄、性别条件。
- **培养方向**：每个方向关联若干要素，每个要素配置要求分级与整数百分比权重，单方向权重合计必须为 100。
- **目标档位**：全局四档（启蒙 / 养成 / 精进 / 冲刺），各方向启用其中若干档并可覆盖文案；家长选择方向时档位必选，默认按匹配度预选一档；手输方向走通用兜底档位。
- 家长在报告内多选培养方向，默认上限 3 个。方向选择是报告属性，在报告详情内查看、留痕与统计，不单独设菜单。列表没有的方向可手输，后台可归并与转正式。
- 数据获取为主动查询：家长绑定子女后按「手机号 + 身份证号」调用第三方接口，绑定即查并定时重试；不做接收列表，未查到按未出结果、信息不一致、接口异常三类归因。
- 方向匹配度在报告整份发布时生成快照，按加权达成度计算，80 及以上为高度匹配、60–79 为较为匹配、60 以下为关联较弱；后续调整方向配置不影响历史报告。
- 检测报告仍由后台审核、整份发布与整份撤回，撤回后 C 端报告、要素解读与培养方向入口同步不可见。
- 替代跟进流程的是**阅读埋点与读完未选名单**：记录谁打开、看到第几项、读完是否选方向，属于数据能力，不含外呼与外发动作。
- 子女身份证号按敏感个人信息处理：采集前单独授权、匹配用哈希、明文加密存储、前后台默认只显后 4 位、后台查看全号需独立权限并留痕。
