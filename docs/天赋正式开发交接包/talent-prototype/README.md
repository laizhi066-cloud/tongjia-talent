# 天赋专项现有原型

本目录采用静态 HTML + ES Modules 实现，覆盖平台管理端、机构业务端（代理商/服务商）和 C 端小程序三个入口。入口路由由 `index.html` 加载，状态保存在浏览器本地演示缓存中。

当前原型重点覆盖：

- 平台会员、家长关系、线下付费和独立报告分册发布/撤回；
- 第三方检测结果接收、去重、规则匹配、异常重试、报告和要素解读发布；
- 代理商引流会员与已发布内容查询；
- 服务商 → 培养计划链路，以及平台审核、退回、重新提交和上/下架；
- C 端培养计划、检测报告、要素解读三个入口；本轮正式口径改为一次只选择一个培养计划及其负责服务商，再确认共享并推送；
- 授权按服务商隔离，停用机构、撤回报告或取消授权后同步收紧可见范围。

## 本地打开

在本目录启动任意静态文件服务后访问 `index.html`。例如：

```text
npx serve docs/customer-review/talent-prototype
```

原型只使用本地演示状态，不连接生产接口；刷新页面会保留已执行的演示操作。业务口径、角色权限和本轮调整记录见上级目录的《同佳系统二期建设报价单 V5.2 天赋智脑整合留痕.md》。

## 2026-09-23 天赋计划重梳理口径

以下规则是全新正式项目当前口径，原型演示数据不作为兼容要求：

- 要素解读必须完整走“检测结果 → 后台分级 → 固定注解 → 年龄/性别条件 → 培养内容”的注解链路，并保存本次命中的规则、分级、注解和内容快照。
- 培养计划必须经过草稿、提交、平台审核通过或退回、修改重提、上架/下架；未审核通过的计划不能推荐或推送。
- 客户一次只确认一个培养计划及其对应的服务商，推送按一次选择建立一条授权，失败可重试但不得重复授权。
- 报告发布权收回到平台审核发布流程。服务商负责培养计划与线下服务，不提供独立的报告发布入口；服务商可在授权范围内只读查看已发布内容。
- 旧原型中的多选、下级机构、课程及服务商发布报告动作属于历史留档，正式实现不迁移。

## 培养方向录入

代理商登记客户时先从标准培养方向中多选（例如艺术类、舞蹈类、篮球、逻辑思维和专注力），没有合适类别时再填写“其他方向”。保存的数据同时保留标准方向标识、方向类别和客户原始补充文本，供后续培养计划匹配与平台归类。
