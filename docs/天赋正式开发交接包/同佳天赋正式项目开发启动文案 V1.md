## 最新业务规则补充

### 对象和关系

- 平台机构：代理商或服务商，一期对外单选类型；机构下可有多个登录用户。
- 用户属于机构，用户分配角色；角色配置菜单、操作及数据范围。代理商引流关系、服务商授权关系必须在角色数据范围之外继续校验。
- 服务商就是培训服务主体；不建立独立培训机构或课程对象，不为其开账号。
- 服务商维护绑定本服务商的培养计划；平台可代服务商建计划并参与审核，平台要素级培养内容独立于服务商计划。
- 孩子本人无手机登录；家长账号负责 C 端访问。家长手机号可以被该家长的多个孩子引用，导入不能因此误判成重复家长。
- 删除保护：有引用、已提交/发布或需追溯的业务记录按规则停用、撤回或保存历史；不能把所有对象都实现成无条件物理删除。

### 权限矩阵

| 操作 | 平台 | 代理商 | 服务商 | C 端 |
|---|---|---|---|---|
| 会员查看 | 角色数据范围内 | 引流归属与角色范围交集 | 有效业务授权与角色范围交集 | 本人或有效家长关系 |
| 会员新增与提交 | 有操作权限可执行 | 登记所属会员、草稿、提交 | 不因有查看权就开放登记 | 不新增后台会员 |
| 接收/匹配检测结果 | 有操作权限可执行 | 无 | 无 | 无 |
| 报告审核 | 平台审核权限 | 无 | 无 | 无 |
| 报告发布 | 有权限且满足条件 | 无 | 已获报告授权且满足发布条件 | 无 |
| 整份报告撤回 | 有撤回权限 | 无 | 无 | 无 |
| PDF 补充/替换 | 有操作权限 | 无 | 无 | 无 |
| 培养计划 | 维护平台计划，审核服务商计划 | 查看已发布可见内容 | 维护自己计划并提交审核 | 选择推荐计划 |
| 业务授权管理 | 会员管理下授权列表 | 无 | 无管理按钮 | 确认/更新/取消自己的共享 |

服务商只能看到被授权且已发布的报告；代理商和 C 端仅可见已发布范围。撤回报告后外部各端不可查看，平台有权限人员保留处理入口。以上不能用一条“所有角色只看已发布”替代。

### 发布与原始报告

- 原始报告取自检测系统，只有第三方结果更正或已确认更新理由才形成新版本；不能手工随意篡改原始结论。
- 规则匹配生成要素解读及计划推荐结果，并保存生成时的年龄、性别、规则和内容依据；查询时显示当次结果。
- 历史留存后台，C 端只读当前生效内容；不提供历史回滚。
- 发布先核对审核结果与可开放分册，弹窗选择至少一册，一次提交发布；撤回作用于整份报告。
- PDF 与分册开放范围相同：不能只开放一册却把包含全部未开放内容的完整 PDF 无限制给 C 端。第三方若只给整份 PDF，要明确开放范围和文件提供方案，不能私自承诺拆 PDF。
- 已下载到用户本地的文件无法由系统物理撤销；撤回要求系统内入口和后续文件访问失效。

### AI 和规则闭环

- “158 项”是当前约定匹配范围，目录可维护但 AI 不可自行添加第 159 项作为检测结论。
- 自定义方向优先尝试归入已配置大类，同一大类复用规则；没有对应方向时产生草稿及运营缺口提醒。
- 规则草稿、注解和内容经过人工核实后才正式生效。新方向的基础规则可以独立保存和审核；面向 C 端推荐的具体计划必须绑定有效服务商并完成审核上架。
- 外部缺失检测数据不能由 AI 补造。AI 临时结果仍是待审建议，不能绕过审核直接参与正式发布。
- 匹配只说明结果与培养方向、已审核内容之间的关系，不能生成确定性人生结论。
- 第三方 AI 调用失败有可追溯状态；专业阈值、权重和缺失兜底由业务确认，开发者不能凭空编造。

## 验收最低场景

1. 同一家长登记两个孩子成功；一个孩子建立第二位有效家长被阻止；关系更换后旧家长失去访问。
2. 导入有正确行、错误行、重复行和同家长多孩子行；预览、修正、确认的结果一致，重复提交不重复创建。
3. 代理商 A 无法通过列表、详情 ID、导出、PDF 地址看到代理商 B 的会员；服务商无授权同样不能访问。
4. 第三方重复回传、更正回传、身份未匹配、要素缺失分别进入正确状态，不覆盖已发布原文。
5. 报告生成可追溯到源结果和命中规则；无分级/注解/内容时显示具体缺口，人工补齐再处理。
6. 发布前弹窗提示，选择分册后整份发布；代理商无发布权限；服务商仅能只读查看授权范围内已发布报告。
7. 撤回、授权取消、角色停用和机构停用后，刷新、直接详情请求、导出与文件请求都失效。
8. 服务商 A 无法修改服务商 B 的计划；计划未绑定有效服务商时禁止提交。
9. 计划退回 → 修改 → 重提 → 审核 → 上架 → 推荐候选 → 单选 → 共享确认 → 服务商只读会员详情可见。
10. C 端切换孩子后报告、要素、计划和未提交选择全部切换，不残留上一个孩子数据；刷新后已确认选择仍存在。
11. 新方向 AI 建议不自动启用；人工审核后形成可用规则/内容，并可在命中详情追溯。
12. 手机端列表、弹窗、返回、底部导航、空状态、加载和失败重试实测；下拉、日期、数字、关联选择器按字段使用。
13. 重启服务后真实数据仍在；真实登录鉴权生效；未接第三方的测试数据不得混入生产或被称为“对接完成”。
