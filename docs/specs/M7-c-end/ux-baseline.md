- 组件优先 Wot，未退化为原生标签堆砌。

## 4. M7 必做验收（建议写入 M7 spec）

1. **Wot 优先**：能用 `wd-*` 的按钮、输入、选择器、单元格、弹层、页签、反馈、图标，不用原生；原生仅限微信开放能力。
2. **尺寸**：390 设计；340 无横向溢出；可点区域 ≥44px；固定底栏 + 安全区；内容不被胶囊/状态栏/键盘遮挡。
3. **状态**：加载、空、错误、未登录、账号停用、无权限、提交中、网络失败，逐页有明确表现。
4. **视觉**：只用主题令牌；字号 ≤3 档；暗色可读；不新增重复组件样式；动效克制并尊重减少动效偏好。
5. **真实设备**：iOS/Android 微信真机 + H5；截图 390/340、亮/暗；关键路径 6 条。
6. **门禁**：`pnpm client:typecheck`、`client:build:h5`、`client:build:mp`、`client:check:wxss`；`wot lint` 无新增 warning。

## 5. 结论

现状的 Wot/主题基础是好的，主要缺口不是“组件没用 Wot”，而是 **PRD 4 栏/15 页的重建、390/340 视觉基线、微信真机安全区、状态完整性**。M7 开工前先按本表建截图基线，再改页面，避免“改完才发现体验退化”。
